Tea Timer App
Tea Timer App — это веб-приложение для чайных церемоний, которое позволяет пользователям выбирать различные сорта чая, следить за временем заваривания, а также добавлять чаи в избранное, оставлять комментарии и делиться впечатлениями. Приложение также предоставляет полезную информацию о чае во время заваривания и включает возможность воспроизведения эмбиентной музыки для создания атмосферы.

Основной функционал
Выбор чая: Пользователи могут выбирать из предустановленной базы данных сортов чая.
Избранное: Возможность добавления чая в избранное для зарегистрированных пользователей.
Регистрация и авторизация: Для сохранения истории заваривания и добавления чая в избранное.
Эмбиент музыка: Воспроизведение музыки с YouTube во время заваривания.
Интересные факты о чае: Отображение интересной информации о чае во время заваривания.
История завариваний: Сохранение истории завариваний для авторизованных пользователей.
Комментарии: Возможность оставлять комментарии к конкретным сортам чая или церемониям.
Добавление новых чаев: Пользователи могут добавлять собственные сорта чая с указанием времени заваривания для каждого пролива.
Используемые технологии
Backend:

NestJS — фреймворк для создания серверных приложений на TypeScript.
GraphQL — язык запросов для API.
TypeORM — ORM для работы с базами данных.
PostgreSQL — реляционная база данных.
Frontend:

Next.js — фреймворк для React-приложений с поддержкой SSR и SSG.
React — библиотека для создания пользовательских интерфейсов.
CSS Modules — для стилизации компонентов.
DevOps:

Docker — контейнеризация приложений.
Docker Compose — инструмент для управления многоконтейнерными Docker-приложениями.
Как запустить проект
1. Клонирование репозитория
Сначала клонируйте репозиторий на вашу локальную машину:

bash
Копировать код
git clone https://github.com/yourusername/tea-timer-app.git
cd tea-timer-app

2. Настройка окружения
Запросите .env файл с данными для для ДБ

3. Запуск Docker контейнеров
Убедитесь, что Docker и Docker Compose установлены на вашем компьютере.

Запустите контейнеры с помощью команды:

bash
Копировать код
docker compose up -d
Это создаст и запустит контейнеры для базы данных PostgreSQL.

4. Инициализация базы данных
При первом запуске база данных будет инициализирована с помощью скрипта init.sql, который находится в корне проекта.

5. Запуск Backend
Перейдите в папку backend и установите зависимости:

bash
Копировать код
cd backend
npm install
Затем запустите сервер:

bash
Копировать код
npm run start:dev
6. Запуск Frontend
Перейдите в папку frontend и установите зависимости:

bash
Копировать код
cd ../frontend
npm install
Запустите приложение:

bash
Копировать код
npm run dev
7. Доступ к приложению
После запуска серверов:

Откройте браузер и перейдите по адресу http://localhost:3000, чтобы увидеть фронтенд приложения.
Сервер GraphQL будет доступен по адресу http://localhost:4000/graphql.
Как пользоваться
Зарегистрируйтесь или авторизуйтесь для использования всех функций приложения.
Выберите ваш любимый сорт чая из предложенной базы данных.
Запустите таймер заваривания, выбрав нужный пролив.
Наслаждайтесь эмбиентной музыкой и получайте интересные факты о чае во время заваривания.
Сохраните чай в избранное или оставьте комментарий после завершения церемонии.
